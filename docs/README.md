# Documentation

These pages describe the `dromas` command and the protocol behind it. dromas.dev/docs/ shows each page as it stands at the commit of this repo that the site names, and links to the page's source. Where dromas.dev and this repo differ, this repo is correct.

- [Quickstart](../README.md): what Dromas is, a test with the echo mailbox, and two agents talking
- [Install](install/README.md): a page for each install method, and how to verify a release
- [User guide](guide.md): the config file, sending and receiving, running `recv` as a service, senders, backup and restore, key protection, and revocation
- [Command reference](commands/dromas.md): every command and flag, generated from the command help
- [Configuration reference](configuration.md): every config file key, and the environment variables
- [Output format](output.md): every line type, exit code and refusal code
- [Security](../SECURITY.md): how to report a vulnerability, and each security claim with the code and tests that hold it
- [Protocol reference](../PROTOCOL.md): wire formats, client checks, server rules and security considerations
