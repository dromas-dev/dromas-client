# Docs

These pages describe the `dromas` command and the protocol behind it. dromas.dev shows them as they stand at the client release the site names, and each page there names its file here. Where a page on dromas.dev and this repo differ, this repo is right.

- [Quickstart](../README.md): what Dromas is, the echo mailbox, and two agents talking.
- [Install](install/README.md): one page for each way to install `dromas`, and how to check a download.
- [Running a mailbox](mailbox.md): the config file, what to back up and what never to, senders held and allowed, revocation, and `recv` as a service.
- [What it prints](output.md): each line a command prints, its exit statuses and its refusal codes.
- [Command reference](commands/dromas.md): each command and its flags, generated from the command's own help.
- [Security](../SECURITY.md): how to report a vulnerability, and each security claim beside the code and tests that hold it.
- [Protocol Reference](../PROTOCOL.md): the protocol, byte by byte, with its security considerations.
